快速抽選（手機來回切換用） 1. 先選縣市（也可用「商品」「時間」再篩），或按 ⭐ 只抽「我的門市」；每間店旁有「▶ 只抽這店」可以一店一店抽
2. 按「開啟抽選」會跳到 LINE；抽完切回瀏覽器，會自動標記完成並排好下一個
3. 再按一次「開啟下一個」即可，一路按到底。下方每一列也可以直接點
💡 若切回來時停在 LINE 的網頁分頁，請切回本頁分頁；或勾「用同一分頁開啟」改用返回鍵回來

連結更新（管理模式）

改完會立刻存在這台裝置的瀏覽器，抽選頁馬上生效。要讓大家看到，請按「下載 data.js」後把檔案覆蓋到網站的 data.js（例如 GitHub Pages 直接 commit）。
每間門市可以直接「貼上 FB 貼文」：只要貼文裡每個商品旁有 lin.ee/… 或 line.me/… 連結，就會自動解析成商品列表。
開啟時：商品連結、抽選時間、缺少門市以來源為準，FB 粉絲頁與 LINE ID 仍用本頁資料。關閉時：完全用 data.js / 本頁手動輸入的資料。
